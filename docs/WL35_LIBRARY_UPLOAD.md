# Biblioteca y nombres de archivos WL35

En el detalle WL35, «Subir un video» permite elegir un MP4 del equipo o uno de la biblioteca. Se conserva el endpoint de carga y su trabajo en segundo plano: carga y convierte, pero no inicia reproducción (`play_after_upload=false`). La biblioteca se copia temporalmente desde una fuente local o privada identificada; el original permanece intacto. El archivo temporal se elimina al terminar, también ante fallo. No se aceptan ambas fuentes a la vez, imágenes ni medios eliminados.

Las cargas futuras guardan el nombre original y el índice que devuelve explícitamente el gateway tras una carga correcta. También una carga confirmada con reproducción posterior fallida puede conservar la asociación de archivo cargado. No se deduce el índice desde la cantidad de archivos ni se guardan nombres ante fallo de carga, índice ausente o respuesta de otro dispositivo. Los nombres se muestran en el estado actual y en la lista de SD; el índice sigue siendo la identidad del control. Un archivo histórico sin asociación dice «Nombre de archivo no identificado». Cambios en la SD desde otra aplicación pueden desplazar índices sin que la telemetría permita detectarlo.

La tabla existente `wl35_device_media` incorpora `filename` y permite `media_id` nulo. Una carga directa conserva sólo esta etiqueta, no retiene el MP4 ni crea un medio artificial de biblioteca; su preview puede seguir sin copia disponible. Una nueva carga del mismo medio conserva la etiqueta del índice anterior y asocia el medio al último índice confirmado. El borrado individual reajusta también las filas sin medio y el formato correcto las elimina. Eliminar definitivamente un medio deja su etiqueta SD mediante `ON DELETE SET NULL`.

La migración completa nombres existentes desde `original_name` o nombre de biblioteca. Antes de usar esta función en producción se requiere ejecutar las migraciones según el procedimiento de despliegue existente; no se ejecutaron aquí sobre una base real. El rollback se detiene si hay etiquetas sin medio, antes de modificar la tabla: requiere respaldarlas y resolverlas conscientemente. Con sólo asociaciones de biblioteca, restaura el esquema anterior, que obtiene los nombres desde el medio. Las migraciones se verificaron únicamente con SQLite en memoria; no se ejecutó un contenedor/MySQL real.

Verificación: `php artisan test --filter=Wl35LibraryUploadTest`, regresiones `DevicePlaybackTest` y `FleetUploadProgressTest`, Pint y render Blade local con HTTP simulado. Ninguna prueba envía órdenes a un ventilador real.
